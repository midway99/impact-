# Ассеты

## `rope.glb` — модель верёвки

Положи сюда файл с таким именем, и он подхватится сам: [`RopeModel`](../effects/RopeModel.ts)
ищет его на сборке и, если не находит, строит заготовку кодом. Больше нигде ничего менять не нужно.

Требования к мешу:

- **прямой отрезок** вдоль одной оси — не изогнутый и не смотанный: положение вдоль верёвки
  раскладывается линейно. Какая именно ось длины, неважно, она определяется по габаритам;
- трансформы применены (`Ctrl+A` → `All Transforms`);
- сечение замкнуто, торцы не нужны;
- **UV обязательна** — иначе развёртка придёт пустой;
- густота сетки любая, с числом частиц решателя совпадать не обязана.

Если у модели своя текстура, в [`RopeRenderer`](../effects/RopeRenderer.ts) надо взять материал
из неё вместо процедурного, а `strandRelief` в конфиге поставить в 0: иначе геометрическая
выпуклость прядей наложится на нарисованную.
